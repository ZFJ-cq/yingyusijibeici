# 英语四级遗忘曲线背单词（Vue3 纯前端应用）

一个**无需后端、不使用数据库**的背单词单页应用：所有学习数据都保存在浏览器
`localStorage` 中。基于遗忘曲线安排复习，卡片式记忆。

界面为**移动端 App 风格**：顶部精简标题栏 + **底部 Tab 栏切换**
（看板 / 复习 / 练习 / 统计 / 设置），适配 iPhone 刘海与底部安全区，
也能在电脑上居中显示（内容限宽 680px，形成「App 视口」观感）。

> 「学新词」不占底部 Tab：它是从**首页看板**进入的单独页面，带返回按钮，
> 属于「用完即走」的操作型页面，避免和日常主入口抢位置。

## ✨ 功能特性

| 页面 | 入口 | 说明 |
| --- | --- | --- |
| **首页看板** | Tab | 今日主卡片（智能提示该复习还是学新词）、「待复习 / 新词 / 已掌握」数量、总体进度、今日已复习、三个入口 |
| **学新词** | 首页入口 | 先只显示单词与音标（**点「显示释义」才展开中文释义与例句**，保留自己回想的环节）；【认识 / 不认识】；可自定义每次学习数量；本批进度条与「结束本批」 |
| **复习** | Tab | 可翻转卡片（正面英文，点击翻面显示释义）；显示该词处于**第几次复习节点**与下次间隔；【记得 / 不记得】；「结束复习」后展示本次统计 |
| **练习** | Tab | 独立刷题模式：英译中 / 中译英 / 短句填空（可混合）；**不影响遗忘曲线**；结束汇总正确率与错题，错题一键加入生词本 |
| **统计** | Tab | 学习数据汇总 + 简易图表（状态分布、近 7 天复习活跃度、练习统计） |
| **设置** | Tab | 出词顺序、每次学习数量、记录导出/导入、清空生词本、重置练习统计、重置记录、主题切换、朗读开关与语速 |

**其它**
- 使用 **Web Speech API** 实现单词朗读发音（无需网络、无第三方依赖）。
- 单词**默认乱序**出题，避免按字母序死记；可在设置中切回**正序**。
- 提示与确认使用**应用内 Toast / 弹窗**（不用原生 `alert/confirm`）：样式与主题统一，
  且在 iOS「添加到主屏」独立运行等场景下不会被浏览器忽略。
- 全部图表用原生 div + CSS 绘制，不引入任何图表库。
- 键盘可达：复习卡片支持 <kbd>Space</kbd> / <kbd>Enter</kbd> 翻面。

## 🔁 遗忘曲线规则（SRS）

- 学完一个**新词**后，自动进入复习计划，复习节点依次为：**1 天 → 2 天 → 4 天 → 7 天 → 15 天**。
- 复习时点击**【记得】**：进入下一个复习节点；完成全部 5 个节点后标记为**已掌握**。
- 复习时点击**【不记得】**：**重置该单词的学习进度，从头开始**（重新回到 1 天节点）。
- 时间统一使用**毫秒时间戳**，前端计算时间差判断是否到达复习时间。

> ⚠️ **硬约束：只有【复习模块】会写 SRS 进度。**
> 【练习模式】无论答对答错，都**不会修改任何单词的复习时间戳**——
> 它只把错题记入「生词本」并累加练习统计。参见 `useStore.js` 中
> `learnWord / reviewRemember / reviewForget` 与 `recordPractice / addToNotebook` 的边界注释。

## ✍️ 练习模式（独立刷题，不影响 SRS）

### 三种题型

| 题型 | 交互 |
| --- | --- |
| **英译中** | 展示英文单词（含音标与朗读按钮）→ 输入框填写中文释义 → 提交判分并展示标准答案 |
| **中译英** | 展示中文释义 → 输入英文单词 → 支持模糊匹配（忽略大小写与空格）与**拼写容错** |
| **短句填空** | 挖空四级例句中的目标单词，如 `How could she ______ her own child? (abandon)` → 补全单词提交判分 |

- 题型可选**混合（推荐）**或单独练习某一种。
- **拼写容错**规则：≤3 字母必须完全正确；4-8 字母允许差 1 个字符（少写一个 `s` 这类笔误会被判对并提示）；
  ≥9 字母允许差 2 个字符。差距超出容错但只差一点时，会提示「很接近，注意拼写」。
- 短句填空只在例句中出现**单词原形**时出题，并过滤掉虚词（长度 < 3）与例句片段，
  因此约 56%（2102 / 3739）的单词可用于该题型；混合模式下不足会自动回退到其他题型。

### 英译中的判分规则

判分逻辑在 `src/utils/practice.js` 的 `judgeMeaning()`，只做**中文语义比对**，三步：

1. **归一化**：用户输入与标准释义都先去掉空格与标点（中英文逗号/分号/顿号/括号等）、统一小写，
   避免全半角与空格造成误判。
2. **切义项**：标准释义去掉词性前缀（`n.` `v.` `adj.` …）后，按 `，,；;、/|` 切成义项列表。
   - `v. 丢弃；放弃，抛弃` → `丢弃` / `放弃` / `抛弃`
   - `adj. 印度的；n. 印度人` → `印度的` / `印度人`
3. **逐条比对，命中任意一条即判对**：
   - 完全相等 → 对
   - 用户输入是某义项的子串（输入 ≥ 2 字）→ 对。例：答「放弃」命中「放弃，抛弃」
   - 某义项是用户输入的子串（义项 ≥ 2 字）→ 对。例：答「放弃，抛弃」包含完整义项
   - **单字只允许完全相等**，否则「的」会命中一大片词

对 3739 词全量的实测结果：

| 检查项 | 结果 |
| --- | --- |
| 每个原始义项单独作答 | **100% 判对**（0 例失败） |
| 明显无关的答案（「跑得快」「明天见」「一本书」） | 误判 **0 次** |
| 略沾边的答案（「计算机系统」含「计算」） | 最多 5 个词误判（约 0.13%） |
| 输入单个汉字 | 「的」「大」→ 0 词；「人」「不」只命中义项本身即该字的词 |

取向是**偏宽松**：答出核心含义（哪怕只写两个字）就算对——这题是自测巩固用的，
判太严反而打击积极性；它只拒绝**明显不相关**的答案。

### 配置项

- **练习词池**：全部单词 / 仅待复习 / 仅已掌握 / 生词本（各自显示可用词数）
- **练习数量**：5 / 10 / 20 题，或自定义 1-100
- **题型**：混合 / 英译中 / 中译英 / 短句填空

### 结束与错题

- 汇总**正确率 / 答对 / 答错**。
- 列出**错题清单**（题型、题面、你的答案、正确答案），支持**一键把全部错题加入生词本**，
  也可逐个加入；生词本中的单词可作为词池做专项练习。
- 生词本可在「练习」页展开查看/移除，也可在「设置 → 清空生词本」整体清空。

## 🌐 部署到 GitHub Pages

### ⚠️ 最容易踩的坑：把源码当成构建产物发布

本项目的**源码 `index.html` 引用的是 `/src/main.js`**（开发入口）。
若把源码直接放到 Pages 上，浏览器会去请求 `https://<user>.github.io/src/main.js`：

```
Failed to load resource: the server responded with a status of 404 ()   main.js
```

结果就是**页面标题正常、但整页白屏**（`<div id="app">` 为空，Vue 从未挂载）。

> **自检方法**：打开线上页面按 F12，看 `<div id="app">` 是否为空；
> 或直接请求 `你的站点路径/src/main.js`，若 404 就说明发布的是**源码**。
> 正确部署后，`index.html` 引用的是 `./assets/index-xxxx.js` 这类**构建产物**。

**结论：Pages 上只放 `dist/` 的内容（`index.html` + `assets/` + `.nojekyll`），不要放 `src/`、`package.json` 等源码。**

### 方式一：GitHub Actions 自动构建（推荐）

项目已内置工作流 `.github/workflows/deploy.yml`，会自动探测项目位置并构建发布：

| 源码位置 | 站点地址 |
| --- | --- |
| 仓库根目录 | `https://<user>.github.io/<repo>/` |
| `beici/` 子目录 | `https://<user>.github.io/<repo>/beici/` |

> 部署路径与源码所在目录**保持一致**，避免「源码在 `/repo/beici`、站点却在 `/repo`」的错位。

步骤：

1. 把本项目推送到仓库 `main` 分支（放根目录或 `beici/` 子目录都行）：
   ```bash
   git init
   git add .
   git commit -m "feat: 四级遗忘曲线背单词"
   git branch -M main
   git remote add origin https://github.com/<用户名>/<仓库名>.git
   git push -u origin main
   ```
2. 仓库 **Settings → Pages** → **Build and deployment → Source** 改为 **GitHub Actions**。
   **关键一步**：若保留默认的 "Deploy from a branch"，Pages 会直接发布你的**源码**，就会白屏。
3. 等 Actions 跑完（仓库 **Actions** 页签看进度），访问上表中的地址。

### 方式二：手动部署构建产物（不依赖 Actions）

```bash
npm run build          # 产物在 dist/
```

把 **`dist/` 里的内容**（`index.html`、`.nojekyll`、`assets/` 整个目录）复制到仓库对应目录，
**替换掉原来的源码文件**，并保持 Pages 的 Source = "Deploy from a branch"。
例如要发布到 `https://<user>.github.io/<repo>/beici/`：

```bash
# 在仓库根目录执行
rm -rf beici && mkdir -p beici && cp -r /path/to/dist/. beici/
git add -A && git commit -m "deploy: 发布构建产物" && git push
```

> ⚠️ `beici/` 里必须**只有构建产物**。若 `src/`、`package.json` 还留在那里，
> 或 `index.html` 仍是源码版本，都会继续白屏。源码建议单独放在仓库其它目录。

### 为什么子路径下也能正常工作

- 应用使用 **hash 路由**（地址形如 `.../#/review`），刷新任意子页面都由 `index.html` 承接，**不会 404**。
- 资源引用使用**相对路径**（`vite.config.js` 的 `base` 默认 `'./'`），
  因此放到 `/repo/`、`/repo/beici/` 等任意子路径都能正确加载，无需改代码。

## 📖 如何使用

通过**底部 Tab 栏**在看板 / 复习 / 练习 / 统计 / 设置之间切换（与手机 App 一致），
「学新词」从**首页看板**的入口进入。

1. **学新词**（首页进入）：设置每次学习数量 → 逐张卡片点击【认识】或【不认识】。
   - 【不认识】的词会排到本批队尾，稍后重学；
   - 【认识】的词加入复习计划，1 天后首次复习。
2. **复习**：到期的单词会出现在复习页，先凭记忆判断，**点击卡片可翻面**看释义。
   - 【记得】进入下一节点；【不记得】重置进度从头再来；
   - 结束展示本次「记得 / 不记得」统计。
3. **练习**：选词池 + 题量 + 题型 → 逐题作答 → 汇总正确率与错题 → 错题可加入生词本。
   - 这是**独立刷题**，答错不会影响遗忘曲线的复习时间。
4. **统计**：查看整体进度、近 7 天复习趋势与练习统计。
5. **设置**：切换主题与出词顺序、调整每次学习数量与朗读、导出 / 导入备份、
   清空生词本、重置练习统计、重置学习记录。

> 💡 **乱序**：默认从词库中随机抽词，避免按字母序背诵。若想按字母顺序复习，
> 到「设置 → 出词顺序」切换为「正序」即可。

> 💡 **建议用法**：先「学新词」建立计划 → 每天按时「复习」推进遗忘曲线 →
> 碎片时间用「练习」刷题巩固；练习答错的词进了生词本后，可用「生词本」词池做专项突破。

## 📚 关于词库数据

`src/data/words.js` 内置**完整的四级词库（3739 词）**，每条包含音标、中文释义、例句及例句译文：

```js
{ word: 'abandon', phonetic: "/ə'bændən/", meaning: 'v. 丢弃；放弃，抛弃',
  example: 'How could she abandon her own child?', exampleCn: '她怎么能抛弃自己的孩子？' }
```

- 数据来源：有道四级词汇（正序版）词书，覆盖四级大纲词汇。
- 其中 103 词无例句、60 词无音标，卡片会自动隐藏对应区域。
- 如需换成其他版本词表，只需替换 `WORDS` 数组并保持相同字段结构，其余代码无需改动。

## 💾 数据存储

- 存储位置：浏览器 `localStorage`，键名为 `cet4_forgetting_curve_v1`。
- 存储内容：
  - `progress`：每词的 SRS 进度 `state / learnedAt / reviewsDone / nextReviewAt / lastReviewAt / history`
    （**只有复习模块会写**）
  - `notebook`：生词本 `{ [单词]: { addedAt } }`
  - `practice`：练习统计 `{ sessions, answered, correct }`
  - `settings`：主题、每次学习数量、出词顺序、朗读等偏好
- ⚠️ 清除浏览器数据会一并清除学习记录，建议定期在**设置**页导出备份。
